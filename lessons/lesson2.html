Лабораторная 2 — Развёртывание виртуальной машины

Цели

  • Создать простую VM (Ubuntu) в облаке или локально (VirtualBox).
  • Подключиться по SSH и выполнить базовую настройку.

Шаги (вариант для Ubuntu VM)

  1. Создай VM на провайдере (DigitalOcean, AWS EC2 или локально в VirtualBox).
  2. Выбери образ Ubuntu 22.04 (или 20.04).
  3. Открой SSH (в случае публичного провайдера — добавь ключ или временный пароль).
  4. Подключись: ssh user@IP_ADDRESS.
  5. Обнови систему: sudo apt update && sudo apt upgrade -y.
  6. Установи curl и nginx: sudo apt install -y curl nginx.
  7. Проверь, что nginx запущен: sudo systemctl status nginx, открой IP в браузере.

Команды (копировать)

ssh root@IP_ADDRESS
sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx
sudo systemctl enable --now nginx
curl -I http://localhost

Ожидаемый результат

На публичном IP должна открываться страница nginx (по умолчанию). Сделай скриншот и положи в папку `lesson2_results/`.

Если работаешь локально с VirtualBox — используй проброс порта (например 8080 → 80) или host-only сеть.
