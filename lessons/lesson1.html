Лабораторная 1 — Введение в облачные технологии

Кратко: что такое облако, модели сервиса (IaaS, PaaS, SaaS), типы развертывания (public/private/hybrid).

Цели

  • Понять ключевые понятия облака.
  • Уметь сравнивать IaaS, PaaS, SaaS.
  • Подготовиться к практическим заданиям (создание VM и развёртывание).

Требования

  • Браузер, доступ в интернет.
  • Аккаунт на любом облачном провайдере (по желанию): DigitalOcean / AWS / GCP / Azure (не обязателен).

Задание (шаги)

  1. Прочитать короткую статью (поискать "what is cloud computing").
  2. Сделать скриншот панели любого облачного провайдера (можно тестовый аккаунт).
  3. Сформулировать краткое сравнение IaaS/PaaS/SaaS (3–5 предложений) и вставить в текстовый файл `lesson1_answer.txt`.

Ожидаемый результат

Файл `lesson1_answer.txt` с кратким сравнением; скриншот панели облака (если есть).
