Лабораторная 3 — Развёртывание статического сайта

Цели

  • Разместить статический сайт на nginx (VM из урока 2).
  • Настроить базовую структуру сайта и проверить доступность по IP.

Шаги

  1. Скопируй файлы сайта на сервер (scp или rsync):
    scp -r ./site_files root@IP_ADDRESS:/var/www/my-site
  2. Создай nginx конфиг: /etc/nginx/sites-available/my-site (пример ниже).
  3. Включи сайт и перезагрузи nginx: sudo ln -s /etc/nginx/sites-available/my-site /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl reload nginx.

Пример nginx конфигурации

server {
    listen 80;
    server_name _;
    root /var/www/my-site;
    index index.html;
    location / {
        try_files $uri $uri/ =404;
    }
}

Проверка

Открой IP сервера в браузере — должен показываться твой сайт. Сделай скриншот и помести его в `lesson3_results/`.
